# Credit Risk Classification: Traditional ML vs Deep Learning

**Author:** Eloi Iradukunda

## Overview

This project predicts whether a client will default on their credit card payment, using demographic characteristics and six months of historical billing data. It systematically compares traditional machine learning algorithms (Logistic Regression, Random Forest) with deep learning architectures (Feedforward Neural Networks with Dropout and Batch Normalization) across a stratified train/validation/test split.

The selected overall best model, a Tuned Random Forest, achieved a test ROC-AUC of **0.7773** and an accuracy of **0.7897**. The full methodology, learning curve analysis, and business interpretations are detailed in the final report submitted with the project.

## Dataset

- **Source:** UCI Machine Learning Repository (Default of Credit Card Clients Dataset, Taiwan 2005)
- **File:** `UCI_Credit_Card.csv` (30,000 rows × 24 attributes)
- **Target:** `default` (0 = No Default, 1 = Default)
- **Predictors:** Demographic data (Age, Sex, Education, Marriage) and six months of historical repayment statuses, bill statements, and previous payments.
- **Note:** The raw dataset is not included in this repository to prevent clutter and respect data hosting guidelines. The compressed data (`UCI_Credit_Card.zip`) and generated model weights are stored in the linked Google Drive folder.

## How to Run

### Google Colab (Recommended)

1. Upload `UCI_Credit_Card.zip` to your Google Drive at `MyDrive/IML/Eloi_Iradukunda_Summative_Project/`.
2. Open `Eloi_Iradukunda_Credit_Risk_Classification.ipynb` in Google Colab.
3. Select **Runtime → Run all**. Allow Google Drive access when prompted.
4. Outputs, metrics, and model weights will be saved to your Colab working directory, and the final cell will copy them directly to your Drive folder.

### Local Machine

```bash
git clone https://github.com/Mr-Eloi/Eloi_Iradukunda_Summative_Project.git
cd Eloi_Iradukunda_Summative_Project
pip install -r requirements.txt
jupyter notebook Eloi_Iradukunda_Credit_Risk_Classification.ipynb
```

If running locally, skip the Google Drive mount cell and ensure your local `DATA_PATH` is set to the unzipped `UCI_Credit_Card.csv`.
